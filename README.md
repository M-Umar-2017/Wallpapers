# Wallpapers

A collection of enhanced desktop wallpapers.

## Contents

The `catpuccin-wallpapers` directory contains high-resolution JPEG wallpapers. The images have been upscaled and quality-optimized for modern displays.

## Collection

- Abstract and minimalist designs
- Fantasy and science-fiction artwork
- Landscapes, cityscapes, and weather scenes
- Character and animation-inspired wallpapers
